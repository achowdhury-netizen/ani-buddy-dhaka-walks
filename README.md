# AniBuddy Pet Connect

Create a mobile-first interactive prototype called AniBuddy.

AniBuddy is a Dhaka-based pet lifestyle, social, entertainment and community platform. Its tagline is “Find Your Pack.”

DESIGN STYLE

Create the interface for a mobile screen approximately 390 × 844 pixels.

Use:

- White background

- Soft blush pink

- Light rose pink

- Deep rose pink for primary buttons

- Black and dark gray text

- Rounded cards

- Clean modern typography

- Minimal shadows

- No glassmorphism

- No heavy gradients

- No cartoon pet illustrations

Use the uploaded AniBuddy Bangladesh-map-and-paw logo throughout the app.

Use the uploaded Bangladeshi pet photographs for profiles and content cards.

BOTTOM NAVIGATION

Create five navigation items:

1. Home

2. Friends

3. Events

4. Services

5. Profile

SCREEN 1: HOME

Include:

- Greeting: “Hi, Farah”

- Location: “Dhaka, Bangladesh”

- Notification and message icons

- Large Find My Friend feature card

- Button: “Find Pets Nearby”

- Trending Pet Content section

- Nearby Events section

- Community, Events, Services and Challenges shortcuts

- Community Highlight pet profile

SCREEN 2: FIND MY PET WALK FRIEND

Include:

- Nearby, Matches and Requests tabs

- Simple Dhaka map with pet location pins

- Filter: Within 3 km

- Four pet profiles using the uploaded pet photos

- Pet name, age, type, distance and personality tags

- “Invite for Walk” button

- “View Profile” option

Use these dummy profiles:

- Tommy, 2-month-old Deshi puppy, 0.6 km away

- Mimi, 3-month-old Persian mix kitten, 1.1 km away

- Snowy, 2-month-old Persian kitten, 1.4 km away

- Luna, 3-month-old Persian mix kitten, 2.2 km away

SCREEN 3: PET PROFILE

Show:

- Large pet photograph

- Name, gender, age and breed

- Location

- Interests and personality tags

- Owner information

- Availability for walks

- “Invite for Walk” button

SCREEN 4: WALK REQUEST

When the user taps “Invite for Walk,” open a modal asking:

- Select date

- Select time

- Select meeting location

- Add a short message

After submission, display:

“Walk request sent to Tommy’s owner!”

Add buttons:

- View Request

- Return Home

SCREEN 5: NOTIFICATIONS

Include sample notifications:

- “Someone is interested in a walk with Tommy!”

- “Your walk request has been accepted.”

- “New adoption event near Dhanmondi.”

- “A pet sitter sent an offer for your post.”

SCREEN 6: EVENTS

Include:

- Pet Walk at Suhrawardy Udyan

- Playdate Meetup at Gulshan Lake Park

- Adoption Drive at PAWS Shelter, Dhaka

- Pet Carnival in Banani

Each event should have:

- Date

- Time

- Location

- Number attending

- Join Event button

SCREEN 7: SERVICES

Include:

- Veterinarians

- Groomers

- Trainers

- Pet shops

- Pet sitting

Show dummy partner businesses and promotional offers.

SCREEN 8: PROFILE

Include:

- User profile

- User’s pets

- Past walks

- Joined events

- Saved services

- Settings

FUNCTIONALITY

Make all buttons clickable.

Use local dummy data. No real payments are required.

Allow users to:

- Open pet profiles

- Send walk invitations

- Join events

- Save services

- View notifications

- Navigate between every screen

Add toast messages after actions such as:

- “Walk invitation sent”

- “Event joined”

- “Offer saved”

Make the interface responsive but prioritize the mobile layout.

Do not create desktop-style sidebars.

Make it presentation-ready and realistic.
